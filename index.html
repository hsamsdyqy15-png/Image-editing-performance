نشر الموقع مجاناً على GitHub Pages

الموقع مبرمج بالكامل كملف مستقل index.html بدون الحاجة لأي خادم. يمكنك رفعه على GitHub Pages في 3 خطوات بسيطة:

1
تحميل ملف index.html

اضغط على زر "تحميل ملف index.html" بالأسفل لحفظه مباشرة على جهازك.

2
إنشاء مستودع على GitHub

ادخل إلى github.com/new وأنشئ مستودعاً عاماً جديداً، ثم ارفع ملف index.html إليه.

3
تفعيل GitHub Pages

من المستودع، اذهب إلى Settings ➔ Pages واختر النشر من فرع main ثم Save. سيصبح موقعك متاحاً برابط مجاني فوري!
